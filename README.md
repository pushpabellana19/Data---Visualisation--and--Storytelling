# Data Visualization and Storytelling — Superstore Analysis

## Project Overview
This project analyzes Superstore sales and profit data using Tableau Public to understand business performance and identify useful trends.

## Project Objectives
- Analyze sales by product category.
- Compare profit across product categories.
- Explore sales by region.
- Compare profit by region.
- Understand monthly sales trends.

## Tools Used
- Tableau Public
- Superstore Dataset

## Dashboard and Story
The Tableau dashboard and story present sales, profit, regional performance, and monthly sales trends through interactive visualizations.

**Tableau Public Link:**  
https://public.tableau.com/authoring/Data_Visualisation_Finaltwbx/SalesbyProductCategory#1

## Key Takeaways
- Compare sales and profit across product categories.
- Explore regional differences in sales and profitability.
- Use monthly sales trends to support business planning.

## Conclusion
This project demonstrates how data visualization and storytelling can help communicate business performance and support data-driven decision-making.
